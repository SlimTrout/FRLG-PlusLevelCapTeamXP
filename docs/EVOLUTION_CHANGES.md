# Evolution changes

Every evolution method that differs from FRLG+ (and from Modern Emerald, for the Pokémon that came from it).

FRLG has no clock, so "day" and "night" work like FRLG+'s Espeon and Umbreon: **outdoors** counts as day, **indoors or in a cave** counts as night. Items that an evolution needs are never shuffled by the item randomizer.

## Trade evolutions → level up

Trading is no longer needed. Trade evolutions that needed a held item now happen at a set level while holding that item (all of these items can be found in FRLG+), and the item is used up. FRLG+'s Link Bracelet still works too.

| Evolution | FRLG+ | Now |
|---|---|---|
| Kadabra → Alakazam | Trade | Level 37; or Use a Link Bracelet |
| Machoke → Machamp | Trade | Level 37; or Use a Link Bracelet |
| Graveler → Golem | Trade | Level 37; or Use a Link Bracelet |
| Haunter → Gengar | Trade | Level 37; or Use a Link Bracelet |
| Onix → Steelix | Trade holding a Metal Coat | Level 30 while holding a Metal Coat (used up); or Use a Link Bracelet while holding a Metal Coat |
| Scyther → Scizor | Trade holding a Metal Coat | Level 30 while holding a Metal Coat (used up); or Use a Link Bracelet while holding a Metal Coat |
| Poliwhirl → Politoed | Trade holding a King's Rock | Level 37 while holding a King's Rock (used up); or Use a Link Bracelet while holding a King's Rock |
| Slowpoke → Slowking | Trade holding a King's Rock | Level 37 while holding a King's Rock (used up); or Use a Link Bracelet while holding a King's Rock |
| Seadra → Kingdra | Trade holding a Dragon Scale | Level 40 while holding a Dragon Scale (used up); or Use a Link Bracelet while holding a Dragon Scale |
| Porygon → Porygon2 | Trade holding an Up-Grade | Level 30 while holding a Up-Grade (used up); or Use a Link Bracelet while holding a Up-Grade |
| Clamperl → Huntail | Trade holding a Deep Sea Tooth | Level 30 while holding a Deep Sea Tooth (used up); or Use a Link Bracelet while holding a Deep Sea Tooth |
| Clamperl → Gorebyss | Trade holding a Deep Sea Scale | Level 30 while holding a Deep Sea Scale (used up); or Use a Link Bracelet while holding a Deep Sea Scale |
| Porygon2 → Porygon-Z | (new) Trade holding an Up-Grade | Level 45 while holding a Up-Grade (used up); or Use a Link Bracelet while holding a Up-Grade |
| Rhydon → Rhyperior | (new) Trade holding a Hard Stone | Level 50 while holding a Hard Stone (used up); or Use a Link Bracelet while holding a Hard Stone |
| Dusclops → Dusknoir | (new) Trade holding a Spell Tag | Level 50 while holding a Spell Tag (used up); or Use a Link Bracelet while holding a Spell Tag |

"(new)" means the Pokémon is new in this fork; the old method is Modern Emerald's.

## Unusual conditions → evolution stones

| Evolution | Before | Now |
|---|---|---|
| Magneton → Magnezone | Level up holding a Thunder Stone (Modern Emerald) | Use a Thunderstone |
| Nosepass → Probopass | Level up holding a Thunder Stone (Modern Emerald) | Use a Thunderstone |
| Eevee → Leafeon | Level up holding a Leaf Stone (Modern Emerald) | Use a Leaf Stone |
| Eevee → Glaceon | Level up holding a Water Stone (Modern Emerald) | Use a Water Stone while holding a Never-Melt-Ice |
| Eevee → Sylveon | Level up holding a Heart Scale (Modern Emerald) | Use a Moon Stone |
| Feebas → Milotic | Beauty 170, which FRLG has no way to raise (FRLG+) | Use a Water Stone |
| Roselia → Roserade | Beauty 70 (Modern Emerald) | Level up with Beauty 70+; or Use a Sun Stone |

There is no Ice Stone in Gen 3, and a Water Stone alone still makes Vaporeon, so Glaceon uses a Water Stone while holding Never-Melt-Ice. There is no Fairy type, so Sylveon uses a Moon Stone, the stone of Clefairy and Jigglypuff.

Wyrdeer, Kleavor, Ursaluna, Bloodmoon Ursaluna, Regidrago, Regieleki, Regigigas and Arceus have no evolution or fixed location (as in Modern Emerald); they turn up through the randomizer.
